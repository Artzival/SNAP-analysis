This is a data science app using XGBoost as the algorithm to analyze historical SNAP and demographic data in order to predict future SNAP program participation. I used the public data portal from Central Texas Foodbank at: https://www.centraltxfoodsystem.org/data-portal

In order to get this running, first clone the repository to your device. All you should need is python installed to run it. Ensure that your data is all loaded up (it comes pre-loaded with Central Texas data from 2024 and 2025) and run it.
It will prompt you to put a month and year, it is recommended to stay within one year of the end of historical data analyzed. It will then produce results including line charts and correlation heatmaps, alongside the actual SNAP predictions.
